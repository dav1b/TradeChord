# Licensing status

This repository does not currently declare a repository-wide software or
content licence. Copyright is therefore reserved by the respective rights
holders unless a separate agreement says otherwise.

## Brand assets and guidance

The files in `assets/`, `guidance/`, `tokens/`, and `carousel/` are DataJockey
brand and implementation materials. Their presence in this repository does not
grant third parties permission to use DataJockey trademarks or redistribute the
materials.

Before making this repository public or sharing it outside an authorised
organisation, the copyright holder should add the intended licence and an
explicit trademark policy.

Do not assume that a font may be redistributed merely because it can be
embedded in a website or PDF. Keep purchase records outside Git if they contain
private customer or billing information; record the licence owner, permitted
uses, and source in an internal rights register.

The reviewed commercial EULA allows internal access by employees, partners, and
collaborators only when the appropriate usage licence has been purchased and
the licensee ensures their compliance. It prohibits making the font available
through a public file-transfer or storage channel and prohibits transferring or
sublicensing the font. On that basis, this repository and any clone containing
the commercial font must remain private unless Pangram Pangram provides written
permission or the commercial font is removed.
